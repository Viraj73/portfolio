# Personal Portfolio Website

A personal portfolio built using semantic HTML5, CSS3, and vanilla JavaScript for the NSS NSUT Tech Department induction task.

---

## Tech Stack & Architecture

- **Markup:** Semantic HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **Styling:** Custom CSS3 (CSS Variables for dynamic dark/light theming, CSS Grid, and Flexbox layouts)
- **Scripting:** Vanilla JavaScript (Theme persistence via `localStorage`, dynamic year rendering)
